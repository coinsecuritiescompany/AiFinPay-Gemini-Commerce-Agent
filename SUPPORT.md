# Support

## Questions and integration discussions

Open a GitHub discussion or use the contact route at [aifinpay.io](https://aifinpay.io). Include the version or commit, runtime, expected behavior, actual behavior, and a sanitized reproduction.

## Bugs

Use the bug-report issue template for non-sensitive defects. Do not attach `.env` files, service-account JSON, wallet exports, screenshots containing keys, customer data, or full receipt tokens.

## Security and payment incidents

Do not open a public issue. Follow [SECURITY.md](SECURITY.md). For a suspected live financial incident, stop the affected service, revoke exposed credentials, preserve redacted logs, and identify the last known safe transaction before attempting recovery.

## Commercial use

The public repository does not grant production or commercial rights. Commercial evaluation, pilots, partnerships, OEM use, and production licenses require a written agreement with AiFinPay.
